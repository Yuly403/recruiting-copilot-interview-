# 打招呼话术模板

> 所有对外消息从这里选取参数化模板，不临时从零生成。
> 首次触达、索要附件、约面、拒绝四个关键节点走固定模板，不允许自由生成。

## 变量约定

所有模板共用以下变量，填入前必须校验：

| 变量 | 含义 | 校验规则 |
|------|------|---------|
| `{{candidate_name}}` | 候选人姓名 | 必须匹配当前线程的目标候选人 |
| `{{job_title}}` | 岗位名称 | 必须匹配当前寻源的岗位 |
| `{{company_name}}` | 公司名称 | 必须与 CONTEXT.md 一致 |
| `{{salary_note}}` | 薪资参考 | 如"30-45k × 14"，仅 FAQ 场景使用 |
| `{{interview_time}}` | 面试时间 | 如"周三下午 3:00" |
| `{{feishu_link}}` | 飞书面试链接 | 面试创建后填入 |

## 生成约束（所有模板通用）

- 句子短，每句不超过 25 字
- 专业、友好，不卑不亢
- 不索要私人微信/手机号
- 不承诺 offer 或具体薪资
- 不捏造公司政策或福利
- 不禁用代词（"贵司""您这边"恰当使用）

## 模板清单

### 1. request_attachment_resume — 索要附件简历

```
您好，我这边在看您投递/沟通的{{job_title}}岗位，您的经历和岗位方向整体比较匹配。
为了进一步评估并尽快推进流程，方便的话麻烦您发送一份最新的附件简历，PDF 格式优先。
我这边收到后会尽快帮您安排后续沟通，谢谢。
```

### 2. attachment_followup — 附件简历跟进

```
您好，想跟进一下附件简历这边的情况。
如果您方便的话，可以直接发一份最新 PDF 简历给我，我这边收到后会尽快帮您继续推进流程。
```

### 3. interview_intent_probe — 探询面试意向

```
您好，结合目前了解的信息，您的背景和{{job_title}}岗位匹配度不错。
如果您近期有意向进一步了解这个机会，我这边可以帮您安排一轮面试沟通，您看是否方便继续推进？
```

### 4. collect_availability — 收集面试时间

```
好的，那我这边继续为您安排面试。
想先和您确认下，您最近两个工作日内大致方便参加面试的时间段是哪些？您给我 2 到 3 个可选时间段就可以。
```

### 5. confirm_interview_time — 确认面试时间

```
和您确认一下，咱们先定在{{interview_time}}进行面试，您看这个时间是否方便？
如果可以，我这边确认后会把面试链接发给您。
```

### 6. send_feishu_schedule_link — 发送面试链接

```
您好，面试已经为您安排好了，时间是{{interview_time}}。
飞书面试链接如下：{{feishu_link}}
建议您提前几分钟进入会议，保持网络和设备正常。如果临时有变动，也请尽快在这里和我说一声。
```

### 7. candidate_reject_polite — 婉拒候选人

```
您好，非常感谢您对{{company_name}}和{{job_title}}岗位的关注。
结合当前岗位需求和本轮评估结果，这次我们暂时先不继续推进了。
也感谢您花时间沟通，后续如果有更合适的机会，我们也会再关注。祝您求职顺利。
```

### 8. faq_role_intro — FAQ：岗位介绍

```
这个岗位目前主要聚焦在{{job_title}}相关工作，会结合团队当前业务目标推进具体职责。
如果您愿意，我也可以继续和您介绍后续流程安排。
```

### 9. faq_salary_range — FAQ：薪资范围

```
目前这个岗位的薪资范围大致参考是{{salary_note}}。
具体方案还需要结合您的经历匹配度和后续面试评估来综合确认。
```

### 10. faq_interview_process — FAQ：面试流程

```
目前大致流程是先进行一轮初步面试沟通，后续如匹配会继续安排下一步。
具体节奏我这边会根据您的推进情况及时同步给您。
```

### 11. uncertain_answer_escalate — 不确定的答案

```
您这个问题我先帮您进一步确认一下，确认后我会尽快回复您。
```

## 使用规则

1. **首次触达走模板 1 或 3**：先评估匹配度决定索要简历还是探面试意向
2. **仅对低风险 FAQ（模板 8/9/10）允许在无命中固定模板时做受限生成**，约束同上方「生成约束」
3. **模板变量不跨模板复用**：每个模板独立填充，不从一个会话复制到另一个
4. **若用户覆盖某模板**：只覆盖该条，未覆盖的继续用内置版本
