# 风险控制

Gateway 是写操作的唯一入口。ActionPlan 必须绑定候选人、岗位、操作、消息哈希、定位器、有效期和幂等键；审批发生在计划与实际执行之间。

典型场景：HR 已批准向“候选人甲”发送一段消息。若同一任务再次提交，幂等键阻止重复发送；若另一个任务尝试切换浏览器到“候选人乙”，会话锁阻止并发；若页面出现验证码或连续异常，熔断停止写入；若点击后网络中断，结果被记录为 `result_unknown`，不能自动重试。

RPA Runner 还验证候选人定位、消息哈希、短期执行票据和剩余时间。它默认演练模式，只有显式开启才能点击页面按钮。上述控制降低风险，但不消除外部平台的规则、风控或页面变化风险。
